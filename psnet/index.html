See which apps use your network

psnet puts a traffic graph, every connection with its hostname and owning process, the servers listening on your machine and a packet inspector in one terminal window. Connections made through svchost show the real service behind them.

No capture driver

Most Windows packet tools need Npcap or WinPcap. psnet uses built in Windows APIs and raw sockets instead. The packet inspector needs an Administrator shell.

Questions

Does psnet need Npcap?

No. It uses built in Windows APIs and raw sockets.

Can it block an app from the internet?

Yes. The firewall tab blocks and allows apps per application from the TUI.
