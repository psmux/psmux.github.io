01 / flagship

psmux

Native tmux for Windows, written in Rust on ConPTY.

psmux drives Windows ConPTY directly and speaks the tmux command language. It reads your existing .tmux.conf and tmux themes. Install it and you get three identical binaries, psmux, pmux and tmux, so old scripts keep working. It needs no WSL, Cygwin or MSYS2.

  • Windows 10
  • Windows 11
  • MIT
  • v3.3.8
  • 90+ tmux compatible commands and 140+ format variables
  • Mouse support, including over SSH on supported Windows builds
  • Copy mode with 53 vim keys
  • Claude Code agent teams open each teammate in its own psmux pane, with no extra config
  • Control mode (-C and -CC) for IDE and plugin authors, iTerm2 tmux gateway included

02 / remote desktop for people and agents

DeskVNC

VNC, RDP and SSH in one native client, with an MCP server for AI agents.

Keep every VNC, RDP and SSH host in one library. Tabs split into panes, and each pane can hold a different machine over a different protocol. The protocol cores are written in Rust and frames are painted through WebGL2. Passwords stay in the OS keychain. There is no account and no telemetry.

It ships dvv, an MCP server. Claude Code or OpenCode can open a saved machine, read the screen, click and type over the ordinary protocol, with nothing installed on the target. Click into the pane and you have control back.

03 / live video

GodwinMix

A live video mixer in Rust that keeps the RTMP output running.

Sources come in by URL: RTMP, SRT, HLS, RTSP, files, or a web page rendered by a real browser. One goes on programme at a time, and programme goes out to one or more RTMP destinations. The output encoder starts once and never restarts, because switching happens upstream on raw video and audio. Sources can join, drop or fail and the stream keeps going.

It is one binary on GStreamer with one HTTP port. The same binary is the gmx command line client and an MCP server, so an agent drives it through the API the web UI uses.

under the hood

psmux builds on two patched crates published from this account: portable-pty-psmux, which passes the ConPTY flags psmux needs, and vt100-psmux, a patched fork of vt100-rust. Windows installs come from Scoop buckets for psmux, TerminalMap, Tmux Plugin Panel and OMP Manager, and Debian users get TerminalMap from a signed APT repository.
