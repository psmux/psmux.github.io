htop, on Windows, in your terminal

pstop is an htop style process viewer for Windows. It shows per core CPU bars, memory, swap, network and GPU meters above a process list you can sort, search, filter and turn into a tree. You can kill a process, change its priority or set its CPU affinity from the keyboard.

More than htop shows

Extra tabs cover disk I/O per process, network bandwidth per process without admin rights, GPU use per process, and the processes running inside WSL.

Questions

Is there an htop for Windows?

pstop is one. It runs in PowerShell or Windows Terminal on Windows 10 and 11, and pstop --install-alias adds an htop command.

Does the per process network tab need admin rights?

No. The README says per process bandwidth works without admin.
